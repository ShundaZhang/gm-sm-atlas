01 / FIELD NOTES

ZA 绑定身份、域参数与公钥

摘要不是简单 SM3(message)。

ZA = SM3(ENTLA || IDA || a || b || xG || yG || xA || yA)
e  = integer(SM3(ZA || M))
ENTLA = 16-bit big-endian bit length of IDA
All field elements above: fixed-width big-endian octets

IDA 是协议定义的字节串，不是隐含操作系统用户名。16 字节 ASCII ID 的 ENTL 是 128 位，即 00 80，不是 00 10。UTF-8 需先数编码字节再乘八。改变 ID、公钥或域参数都会改变 ZA；双方须使用相同上下文。某库默认 ID 不适用于所有协议。

02 / FIELD NOTES

一起阅读签名与验签公式

SM2 签名不是改名曲线上的 ECDSA。

Sign, d∈[1,n−2], fresh k∈[1,n−1]:
(x1,y1) = [k]G
r = (e + x1) mod n
retry if r=0 or r+k=n
s = ((1+d)⁻¹ × (k−r d)) mod n
retry if s=0

Verify, first check r,s∈[1,n−1] and valid PA:
t = (r+s) mod n; reject t=0
(x1′,y1′) = [s]G + [t]PA; reject infinity
accept iff (e′+x1′) mod n = r

签名私钥排除 n−1，因为 1+d 在 mod n 下无法求逆。验签成立的关系是 s+(r+s)d = k mod n。公钥乘法例程可以共用 ECC 机制，外层签名等式仍不同。

对应资料：SM2 English exposition · expired Internet-Draft ↗ · FIPS 186-5 · signatures ↗

03 / FIELD NOTES

Nonce 重用会暴露私钥标量

安全随机数是算法实现的一部分。

For reused k and two valid SM2 signatures:
s1 + (s1+r1)d = k mod n
s2 + (s2+r2)d = k mod n
d = (s2−s1) / (s1+r1−s2−r2) mod n
when the denominator is invertible

Nonce 偏差、部分泄漏和侧信道也可能危险，并非只有完全重用。不能在缺少明确、经分析的 SM2 构造时直接移植 ECDSA 确定性 Nonce 方法。下载测试中的固定 Nonce 是用于复现等式的公开合成值，不是部署建议。

签名是 (r,s) 对，常见编码为固定 32+32 字节或包含两个 INTEGER 的 DER SEQUENCE。DER INTEGER 为有符号数，可能需要前导 00，因此长度可变。身份 / 摘要不匹配、双重哈希、密钥类型混淆和 raw / DER 混淆是常见互操作问题。
