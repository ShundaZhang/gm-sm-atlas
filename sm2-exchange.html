01 / FIELD NOTES

SM2 exchange mixes static and ephemeral keys

A raw ECDH multiplication is not the complete SM2 exchange.

A: static dA, PA=[dA]G; ephemeral rA, RA=[rA]G
B: static dB, PB=[dB]G; ephemeral rB, RB=[rB]G
w=ceil(log2(n)/2)−1  (127 for curveSM2)
x̄1=2ʷ+(xRA mod 2ʷ); x̄2=2ʷ+(xRB mod 2ʷ)
tA=(dA+x̄1 rA) mod n; tB=(dB+x̄2 rB) mod n
U=[h tA](PB+[x̄2]RB)
V=[h tB](PA+[x̄1]RA)
U=V for valid honest inputs

Validate received points and reject infinity or invalid intermediate results. The shortened x-coordinate values are not hashes; their definition is part of the scheme. Both long-term and ephemeral secret scalars are used, so the protocol’s security claims must be read with the specified compromise model. “Uses ephemeral keys” by itself is not a blanket forward-secrecy proof.

02 / FIELD NOTES

Keep A/B ordering fixed in the KDF and confirmations

The same shared point can produce different keys if identities are ordered differently.

K = KDF(xU || yU || ZA || ZB, klen)
inner = SM3(xU || ZA || ZB || xRA || yRA || xRB || yRB)
B confirmation = SM3(02 || yU || inner)
A confirmation = SM3(03 || yU || inner)

B sends the 02-prefixed tag and A checks it; when confirmation is used, A sends the 03-prefixed tag and B checks it. The outer role ordering is A then B even when B executes the calculation. Confirmation proves possession of the derived context under the protocol assumptions; it is not an authorization decision for every application action.

The download implements the algebraic core and both tags, with a test that changing an ID changes the key. It is not a network state machine: timeout, replay handling, role binding, certificate authentication, tag verification and key-release policy still belong to a real protocol implementation.

03 / FIELD NOTES

A protocol can use curveSM2 without using this exchange

Identify the negotiated group and the actual key schedule.

A TLS 1.3 key share on curveSM2 follows the TLS 1.3 handshake and key schedule selected by its profile. Do not label every multiplication on the SM2 curve as the GB/T 32918.3 static-plus-ephemeral exchange above. Likewise, SM2 signatures authenticate a transcript, while the TLS record cipher is an independent symmetric construction.
