国密名称覆盖不同密码功能。

算法族功能公开学习范围
SM1 / SM7对称分组密码名称及应用场景公开，本网站使用的开放资料不包含完整逐轮规范
SM2ECC 签名、加密与密钥交换公开算术及协议，各功能需要独立 API
SM3256 位密码杂凑公开压缩函数，普通杂凑没有秘密密钥
SM4128 位密钥 / 128 位分组密码公开 S 盒、密钥计划及 32 轮核心
SM9基于标识的公钥密码基于双线性对的签名、交换、封装及加密
ZUC序列密码族密钥流生成及独立机密性 / 完整性配置

这里列出主要命名算法族。“所有国密算法”并不是连续 SM1–SM9 的有限清单；行业标准还定义构造、接口和协议。编号缺口不能成为编造 SM5、SM6、SM8 规范的依据。历史或厂商名称须先定位精确一手规范再比较。

02 / FIELD NOTES

承认公开细节的边界

不能用猜测填补缺少的规范。

SM1 与 SM7 是密码产品中使用的对称算法名称；SM7 可见于标签 / 读写器与身份鉴别场景。公开描述不足以重建并独立测试完整核心。因此本网站解释类别及应用边界，不编造轮数、S 盒或通用密钥长度表。

非公开实现应根据接口文档、测试行为、产品范围及相应保障证据评估。规范不公开本身不是安全证明。开源 SM2/3/4 库不能悄悄替代 SM1/7 设备功能。

对应资料：NXP · SM1 / SM7 disclosure limits ↗ · Zhaoxin · GM algorithm families ↗

03 / FIELD NOTES

算法、模式与协议是不同层次

SM4、SM4-GCM 与 TLS 套件是不同对象。

原语定义精确变换，模式或构造加入 Nonce、认证或密钥派生，协议选择身份、密钥、协商及消息顺序。认证模块或产品又有独立保障范围。应比较对应层次：SM2 签名 ↔ ECDSA，SM3 ↔ SHA-256 / SHA3-256，SM4 ↔ AES-128，SM4-GCM ↔ AES-GCM。

SM9 不是另一条 SM2 曲线，ZUC 不是 SM4 的分组模式；二者都需要独立信任及状态模型。

对应资料：RFC 8998 · SM cipher suites for TLS 1.3 ↗ · FIPS 197 · AES ↗ · GB/T 38635 · SM9 series ↗ · GSMA · ZUC and 128-EEA3 / EIA3 ↗
