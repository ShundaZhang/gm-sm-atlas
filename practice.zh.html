01 / FIELD NOTES

运行完整本地参考项目

Python 核心无需安装额外包。

下载参考项目 ZIP ↓

cd gm-sm-atlas-examples
python3 -B test_reference.py
python3 -B demo.py

需要 Python 3.9 或更新。代码包含 SM3 压缩、SM4 扩展 / 加解密、AES-128 加密、curveSM2 / P-256 点运算、SM2 签名验签、C1C3C2 加解密及含确认标签的 SM2 交换算术。命令行 SHA-256 / SHA3-256 对比使用 Python hashlib。

例子中的固定私钥标量与 Nonce 都是刻意公开的合成测试值，不能作为真实密钥，也不要向浏览器实验输入私钥。参考实现是便于阅读、有教学边界但无恒定时间保证的代码，不是认证密码模块。

02 / FIELD NOTES

已知答案加独立实现

十个测试方法覆盖多组数值及拒绝路径。

检查证据
SM3abc 与 64 字节公开向量；10 组含填充边界长度经 OpenSSL 检查
SM4 / AES-128公开单分组答案及每种密码 8 对独立密钥 / 分组
SM2 签名使用明确不同历史测试曲线的草案已知答案；当前曲线与 OpenSSL 双向验签
SM2 加密OpenSSL 加密 ↔ 参考解密及反向，明确 raw / DER 转换
失败路径错误消息 / ID、坏点、零 r、篡改 C2 / C3、禁止标量与超长 ID
交换A / B 共享密钥及确认相同，改变身份改变派生密钥

独立检查使用 OpenSSL 3.6.2。若缺少 CLI，两个独立测试方法会明确跳过，已知答案测试仍运行。安装的 OpenSSL 若缺少算法，独立测试会失败而不假装成功。交换按双方算术结果互检，不是独立认证或网络协议测试。

03 / FIELD NOTES

改变实现前检查精确输出

小的刻意修改应使对应已知答案失配。

可将 SM3 最终异或改成加法或改变 P1 旋转，观察 abc 为何失败；将 SM4 的 L′ 换成 L，观察首轮密钥失配；更换 SM2 签名 ID，观察验签拒绝；比较 SM2 与 P-256 相同标量倍点，结果因域不同而不同。恢复原码后重跑检查。

应将拒绝测试读成安全属性，而不是需要消除的异常。完整生产部署还需侧信道评估、协议互操作及适合应用的保障。

对应资料：NIST SP 800-56A Rev.3 ↗ · GmSSL · upstream implementation ↗
