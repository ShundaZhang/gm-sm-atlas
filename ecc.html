01 / FIELD NOTES

Use mod p for coordinates, mod n for scalars

Mixing the two moduli produces plausible-looking but wrong code.

Curve: y² = x³ + ax + b  (mod p)
Domain: (p, a, b, G, n, h)
Public key: P = [d]G
Point addition / doubling: arithmetic in Fp
Signature scalar arithmetic: mod n

p defines the prime field; n is the prime order of the chosen base-point subgroup; h is the cofactor. They are different integers even when both occupy 32 bytes. The point at infinity is the group identity, not coordinate (0,0). curveSM2 and NIST P-256 are short-Weierstrass prime-field curves with a = −3 mod p and h = 1, but p, b, G and n are different.

02 / FIELD NOTES

Point arithmetic must handle exceptional cases

An affine formula is readable, but is not a fast or constant-time implementation.

P=(x1,y1), Q=(x2,y2)
P≠Q: λ=(y2−y1)/(x2−x1) mod p
P=Q: λ=(3x1²+a)/(2y1) mod p
x3=λ²−x1−x2 mod p
y3=λ(x1−x3)−y1 mod p
P + (−P) = infinity

Modular division means inversion, not floating-point division. Real software commonly uses projective coordinates to avoid an inverse per addition, plus scalar-multiplication strategies chosen for the threat model. Secret-dependent double-and-add branches, table indices, and variable-time inversions can leak keys. “It returns the right point” is only a functional check.

03 / FIELD NOTES

Validate both the point and its encoding

Never decode an attacker-supplied point by assuming it is valid.

Check coordinate bounds, the curve equation, non-infinity and the subgroup condition appropriate to the domain and protocol. An uncompressed public point commonly uses 04 || x || y, with 32-byte big-endian coordinates on these curves. That is 65 bytes, not a universal public-key file format: DER SubjectPublicKeyInfo also carries algorithm identifiers.

A 256-bit ECC private scalar is not a 256-bit security claim. Generic discrete-log work on a suitable 256-bit prime-order group is roughly 2¹²⁸ classical operations. Parameter correctness, protocol assumptions, implementation leakage and future quantum attacks are separate questions.
