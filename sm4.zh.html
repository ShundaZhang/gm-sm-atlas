01 / FIELD NOTES

四个 32 位字经过 32 轮核心

SM4 标准密钥长度为 128 位。

Input block: X0,X1,X2,X3 (big-endian 32-bit words)
For i=0..31:
 Xi+4 = Xi XOR T(Xi+1 XOR Xi+2 XOR Xi+3 XOR rki)
 T = L ∘ τ
 τ: apply the fixed 8-bit SM4 S-box to each byte
 L(B)=B XOR ROTL(B,2) XOR ROTL(B,10)
      XOR ROTL(B,18) XOR ROTL(B,24)
Output: X35 || X34 || X33 || X32

SM4 常被描述为广义 Feistel 类字结构。最终反序是加密的一部分，不是可选字节序。S 盒不是 AES S 盒。128 位明文与 128 位密钥产生 128 位分组；原语内部没有填充。

02 / FIELD NOTES

密钥计划使用不同线性变换

不能混用 L 与 L′。

K0..K3 = MK0..MK3 XOR FK0..FK3
FK = a3b1bac6 56aa3350 677d9197 b27022dc
CKi,j = ((4i+j)×7) mod 256, j=0..3
CKi = four CK bytes in big-endian order
Ki+4 = Ki XOR T′(Ki+1 XOR Ki+2 XOR Ki+3 XOR CKi)
T′ = L′ ∘ τ
L′(B)=B XOR ROTL(B,13) XOR ROTL(B,23)
rki = Ki+4

数据轮与密钥扩展共享字节 S 盒，但旋转不同。加密使用 rk0 至 rk31，解密以相同轮变换使用 rk31 至 rk0，再做相同输出反序。SM4 解密不需要逆 S 盒。

03 / FIELD NOTES

跟踪标准单分组已知答案

这是原语测试，不是 ECB 数据加密建议。

Key   = 0123456789abcdeffedcba9876543210
Input = 0123456789abcdeffedcba9876543210
rk0   = f12186f9
X4    = 27fad345
Output= 681edf34d206965e86b3e94f536e4246

实验显示全部 32 轮密钥和生成字，再以逆序密钥检查解密。OpenSSL 独立测试除公开例子外，还使用多组不同密钥及分组。查表 S 盒易读，但可能经缓存泄漏；数学正确不证明恒定时间。
