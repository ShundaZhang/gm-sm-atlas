01 / HASH

Same bytes, three different 256-bit digests

SM3 and SHA3-256 use the original local core; SHA-256 uses Web Crypto. Input limit: 2048 encoded UTF-8 bytes.

Ready — choose public teaching inputs

Try empty text, abc, 55 and 56 ASCII bytes, then Chinese text. The output shows SM3 A/E registers after each round. Different digests or avalanche behavior do not prove one algorithm is more secure. SHA3-256 is standardized SHA-3, not original Keccak-256.

02 / BLOCK
Observe one block under SM4 and AES-128
Identical key bytes and plaintext are supplied to two different primitives. There is no mode, padding or authentication.
Ready — choose public teaching inputs
The first preset with the default block produces the published SM4 answer 681edf34…536e4246. To reproduce the AES FIPS example, choose the second key and enter 00112233445566778899aabbccddeeff; AES gives 69c4e0d8…70b4c55a. SM4 inverse uses reversed round keys. Round count and trace length are not comparative security scores.

03 / CURVE
The domain determines the point
Only predetermined public scalars are available. This does not generate a private key or a signature.
Ready — choose public teaching inputs
Compare 2G on both curves, then nG. Both generators have order n and give infinity, but their coordinates and parameters differ. The implementation uses exact BigInt arithmetic and a readable variable-time affine formula. It is not a production ECC engine.
