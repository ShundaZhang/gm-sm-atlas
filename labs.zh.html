01 / HASH

相同字节，三种不同 256 位摘要

SM3 与 SHA3-256 使用原创本地核心，SHA-256 使用 Web Crypto；输入上限为编码后 2048 个 UTF-8 字节。

就绪 — 选择公开教学输入

尝试空文本、abc、55 / 56 个 ASCII 字节及中文。输出显示每轮之后的 SM3 A/E 寄存器。摘要不同或雪崩现象不证明某算法更安全。这里 SHA3-256 为标准 SHA-3，不是原始 Keccak-256。

02 / BLOCK
观察一个分组的 SM4 与 AES-128 运算
相同密钥字节和明文输入两种不同原语；没有模式、填充或认证。
就绪 — 选择公开教学输入
第一预设和默认分组产生公开 SM4 答案 681edf34…536e4246。复现 AES FIPS 例子时选第二密钥、输入 00112233445566778899aabbccddeeff，AES 得 69c4e0d8…70b4c55a。SM4 逆运算使用反序轮密钥。轮数及轨迹长度不是安全评分。

03 / CURVE
域决定点
仅提供预定公开标量，不生成私钥或签名。
就绪 — 选择公开教学输入
比较两条曲线的 2G，再计算 nG。两个基点阶均为 n，结果均为无穷远，但坐标及参数不同。实现使用精确 BigInt 与易读的变时仿射公式，不是生产 ECC 引擎。
