Mechanism and implementation

01 / FIELD NOTES

ZUC generates a stateful keystream

A stream cipher is not a 128-bit block cipher.

The original ZUC-128 core takes a 128-bit key and 128-bit IV. It combines a 16-stage 31-bit LFSR, bit reorganization and a nonlinear function with two 32-bit registers and S-box processing. The LFSR operates with arithmetic tied to 2³¹−1, not SM3/SM4’s modulo-2³² word additions. Initialization and working phases are different.

Working output is a sequence of 32-bit keystream words. For encryption, XOR the appropriate bits with the message according to the selected profile. Repeating a key/IV repeats a keystream and exposes relations between plaintexts. Confidentiality alone does not provide integrity.

02 / FIELD NOTES

EEA3 and EIA3 are different uses of the core

Message counters and radio context are part of the input profile.

128-EEA3 provides a confidentiality profile and 128-EIA3 an integrity profile for mobile communications. They define how count, bearer, direction, length and other context are encoded; they are not interchangeable arbitrary calls to “ZUC encrypt.” Test data includes bit-level lengths, so a byte-only harness can miss errors.

Compare ZUC encryption with a complete stream or CTR confidentiality construction, and its integrity profile with the specified integrity algorithm. Comparing “ZUC versus AES” without naming a mode or traffic profile mixes different layers.

03 / FIELD NOTES

A 256-bit ZUC profile has its own specification

Do not extend ZUC-128 by appending key bytes.

3GPP’s newer 256-bit algorithm set includes ZUC-based 256-NEA6, 256-NIA6 and 256-NCA6 specifications in the TS 35.246–35.248 family. These are release-specific profiles with separate initialization, formats and test data. Check the actual release and document version instead of inferring compatibility from the ZUC name.

The atlas explains ZUC’s model and reading route; it does not supply a full radio-protocol implementation. The publisher’s implementation/use conditions should be read alongside a technical specification when integrating it into a product.
