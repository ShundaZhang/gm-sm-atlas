ECC 基础
机制与实现

有限域、标量、点验证及编码

01 / FIELD NOTES

坐标用 mod p，标量用 mod n

混用两个模数会产生看似合理的错误代码。

Curve: y² = x³ + ax + b  (mod p)
Domain: (p, a, b, G, n, h)
Public key: P = [d]G
Point addition / doubling: arithmetic in Fp
Signature scalar arithmetic: mod n

p 定义素域，n 是所选基点子群的素数阶，h 是余因子；即使都占 32 字节，p 与 n 仍是不同整数。无穷远点是群单位元，不是坐标 (0,0)。curveSM2 与 NIST P-256 都是短 Weierstrass 素域曲线，a = −3 mod p、h = 1，但 p、b、G、n 不同。

对应资料：NIST SP 800-186 · domain parameters ↗ · RFC 8998 · SM cipher suites for TLS 1.3 ↗

02 / FIELD NOTES

点运算必须处理特殊情形

仿射公式易读，但不是快速或恒定时间实现。

P=(x1,y1), Q=(x2,y2)
P≠Q: λ=(y2−y1)/(x2−x1) mod p
P=Q: λ=(3x1²+a)/(2y1) mod p
x3=λ²−x1−x2 mod p
y3=λ(x1−x3)−y1 mod p
P + (−P) = infinity

模除法指求逆，不是浮点除法。真实软件通常使用投影坐标避免每次加法求逆，并按威胁模型选择标量乘策略。秘密相关的倍点加分支、表索引和变时求逆会泄露密钥。“返回正确点”只是功能检查。

对应资料：NIST SP 800-186 · domain parameters ↗ · NIST SP 800-56A Rev.3 ↗

03 / FIELD NOTES

验证点与编码

不能假定攻击者提供的点有效。

应检查坐标范围、曲线方程、非无穷远，以及域和协议要求的子群条件。这些曲线的非压缩点通常为 04 || x || y，坐标各 32 字节大端，共 65 字节；它不是通用公钥文件格式，DER SubjectPublicKeyInfo 还携带算法标识。

256 位 ECC 私钥标量不意味着 256 位安全强度。适当 256 位素数阶群的通用离散对数攻击约需 2¹²⁸ 次经典运算。参数正确性、协议假设、实现泄漏及未来量子攻击是独立问题。

对应资料：NIST SP 800-56A Rev.3 ↗ · NIST SP 800-57 Part 1 Rev.5 ↗ · NIST · post-quantum cryptography ↗
