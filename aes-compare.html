AES-256’s key is longer; its block is still 128 bits.

Counting rounds is not a security ranking: an SM4 round transforms one new word, while an AES round transforms the full byte state. They have different nonlinear layers, diffusion and key schedules. Security assessment requires attacks against the exact full algorithm and assumptions, not “32 is greater than 10.”

02 / FIELD NOTES

AES works on a column-major 4×4 byte state

ShiftRows and MixColumns operate on different dimensions.

state[row,col] = input[4×col+row]
Initial: AddRoundKey
Ordinary round: SubBytes → ShiftRows → MixColumns → AddRoundKey
Final round: SubBytes → ShiftRows → AddRoundKey (no MixColumns)
AES S-box: inverse in GF(2⁸), then affine transform
GF polynomial: x⁸+x⁴+x³+x+1 (0x11b)
MixColumns matrix:
 02 03 01 01
 01 02 03 01
 01 01 02 03
 03 01 01 02

SubBytes substitutes every byte. ShiftRows cyclically rotates rows; MixColumns multiplies each column by a fixed GF(2⁸) matrix. AddRoundKey XORs a full 16-byte round key. SM4 instead applies its S-box to a four-byte word and diffuses through 32-bit rotations; copying AES’s state layout into an SM4 port changes the algorithm.

03 / FIELD NOTES

AES key expansion also differs across key sizes

AES-256 has an extra SubWord branch.

Nk = 4 / 6 / 8 words; Nr = 10 / 12 / 14
temp = w[i−1]
if i mod Nk = 0:
 temp = SubWord(RotWord(temp)) XOR Rcon[i/Nk]
else if Nk > 6 and i mod Nk = 4:
 temp = SubWord(temp)
w[i] = w[i−Nk] XOR temp
Generate 4×(Nr+1) words

AES-128’s initial key is the round-zero key; SM4’s FK XOR and T′ expansion are a different procedure. The download includes readable AES-128 encryption so that its ten states can be compared with SM4’s generated words, and validates it with the FIPS known answer 69c4e0d8…70b4c55a plus independent OpenSSL checks. It does not implement AES-192/256 or a production mode API.

Performance depends on implementation, CPU instructions, mode parallelism, message length and setup cost. A vendor’s accelerated result is not a universal SM4/AES speed ratio. Benchmark the same mode, hardware, library build and workload before choosing an engineering path.
