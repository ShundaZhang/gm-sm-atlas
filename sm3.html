01 / FIELD NOTES

Parse bytes into 512-bit blocks and 32-bit words

SM3 returns 256 bits, but its input block is 512 bits.

Append 1 bit; append zeros until length ≡ 448 mod 512
Append original message length as a 64-bit big-endian integer
IV = 7380166f 4914b2b9 172442d7 da8a0600
     a96f30bc 163138aa e38dee4d b0fb0e4e
Each block: 16 initial 32-bit big-endian words

The length suffix is a bit count before padding. For byte input, the first added byte is 80. A 55-byte message fits into one block; a 56-byte message needs a second block for the length. All arithmetic additions below wrap modulo 2³²; rotation counts are reduced modulo 32. Implementations must not rely on unlimited Python integers or signed JavaScript shifts without explicit word handling.

02 / FIELD NOTES

Expansion uses P1 and two related word streams

Do not substitute SHA-256’s sigma functions.

ROTL = 32-bit rotate left
P0(X)=X XOR ROTL(X,9) XOR ROTL(X,17)
P1(X)=X XOR ROTL(X,15) XOR ROTL(X,23)
For j=16..67:
 Wj=P1(Wj−16 XOR Wj−9 XOR ROTL(Wj−3,15))
    XOR ROTL(Wj−13,7) XOR Wj−6
For j=0..63: W′j=Wj XOR Wj+4
Tj=79cc4519 (j<16); 7a879d8a (j≥16)

The first stream has 68 words and the derived stream has 64; confusing these counts or the j+4 reference is a common indexing bug. P0 transforms a compression result; P1 transforms schedule inputs. They serve different positions and use different rotation constants.

03 / FIELD NOTES

Inspect the full 64-round compression update

The output feed-forward is XOR, not addition.

For j<16: FF=A XOR B XOR C; GG=E XOR F XOR G
For j≥16: FF=(A&B)|(A&C)|(B&C); GG=(E&F)|(~E&G)
SS1=ROTL((ROTL(A,12)+E+ROTL(Tj,j)) mod 2³²,7)
SS2=SS1 XOR ROTL(A,12)
TT1=(FF+D+SS2+W′j) mod 2³²
TT2=(GG+H+SS1+Wj) mod 2³²
(A,B,C,D) ← (TT1,A,ROTL(B,9),C)
(E,F,G,H) ← (P0(TT2),E,ROTL(F,19),G)
Vnext=Vprevious XOR (A||B||C||D||E||F||G||H)

After all padded blocks, serialize the eight final words big-endian. For ASCII abc, the result is 66c7f0f4…8f4ba8e0. The browser lab shows all compression rounds and padding length; the Python tests include 55/56/63/64/65-byte boundaries plus independent OpenSSL results. Matching abc alone would not detect every padding or multi-block bug.
